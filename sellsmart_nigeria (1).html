Deployment & Backend Guide

1. Free Hosting Options (Vercel / Netlify / GitHub Pages)

This app is lightweight and optimized for Android mobile browsers. You can host it for free in under 2 minutes:

  • Vercel / Netlify: Drag and drop your project folder containing `index.html`.
  • GitHub Pages: Push code to a repository and enable Pages in repository settings.

2. Upgrading Data Sync (Backend Setup)

Currently, SellSmart NG uses browser localStorage (data stays safely on your phone). To enable multi-device sync across laptops and staff phones:

  • Firebase Firestore (Recommended for SMEs): Replaces `localStorage` with real-time cloud data. Allows offline support & team syncing.
  • Supabase / Node.js + PostgreSQL: Excellent for relational accounting reporting.

Transparency & Payment Guardrail

This demo stores transactions locally for operational management. It does not perform simulated card charging or claim fake bank authorization.
